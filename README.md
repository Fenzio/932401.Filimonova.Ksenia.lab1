# 932401.Filimonova.Ksenia.lab1
# О себе — Искусство и креатив

Лабораторная работа №1. HTML-страница в фиолетово-белой гамме.

**Автор:** Филимонова Ксения, группа 932401

## Что реализовано

- Семантические теги: `<header>`, `<main>`, `<section>`, `<aside>`, `<footer>`
- Секция «Навыки» — маркированный список
- Секция «Проекты» — нумерованный список
- Боковая панель с любимым направлением (скетчинг)
- Форма обратной связи: имя, email, сообщение
- Изображение-аватар с атрибутами `src`, `alt`, `width`, `height`
- Фиолетово-белая цветовая гамма

## Как открыть

Открыть файл `index.html` в любом браузере.

## Валидность

Код проверен через [W3C Validator](https://validator.w3.org/) — без ошибок.
